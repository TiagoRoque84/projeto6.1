# 📌 PRECISA DE TOKEN? Siga estes passos:

## Como Criar Token de Acesso no GitHub

### Passo 1: Acessar Configurações
1. No GitHub, clique na sua foto (canto superior direito)
2. Clique em **Settings**

### Passo 2: Developer Settings
1. Role até o final da página
2. Clique em **Developer settings**

### Passo 3: Personal Access Tokens
1. Clique em **Personal access tokens**
2. Clique em **Tokens (classic)**
3. Clique em **Generate new token** → **Generate new token (classic)**

### Passo 4: Configurar Token
```
Nome: Token para Deploy
Validade: No expiration (sem expiração)
Selecionar:
  ✓ repo (marcar TUDO dentro de repo)
```

### Passo 5: Gerar e Copiar
1. Clique em **Generate token** (fim da página)
2. **COPIE O TOKEN AGORA!** (só mostra uma vez)
   - Exemplo: `ghp_abc123def456ghi789...`
3. **Cole em um bloco de notas** e salve

### Passo 6: Usar no Git
Quando pedir:
```
Username: TiagoRoque84
Password: [COLE O TOKEN AQUI]
```

⚠️ **IMPORTANTE:** O "Password" NÃO é sua senha do GitHub!
É o token que você acabou de criar!
